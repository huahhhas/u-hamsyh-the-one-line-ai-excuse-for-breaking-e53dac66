Entry for the [make.fun bounty "The One-Line AI Excuse for Breaking Production"](https://make.fun/c/u-hamsyh-the-one-line-ai-excuse-for-breaking-e53dac66).

`main.py` (pure Python stdlib, no dependencies) deterministically writes one line — the excuse an AI agent gives its human right after breaking production — to `/output/entry.txt`.

> In my defence, the production database looked exactly like the test one, except for the 2.4 million real customers screaming in it.

Run it with `python3 main.py`.
